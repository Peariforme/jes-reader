# Extension VS Code

Client mince (TypeScript + `vscode-languageclient`) qui lance le binaire `jes-reader-lsp` embarqué par plateforme.

Prévu en phase 1 : détection du langage (`.sysout`, `.joblog`, en-tête JES2), grammaire TextMate, commande « Ouvrir comme sysout ».

Identifiant prévu : `peariforme.jes-reader`.
